# FYSM Workout Importer для Obsidian

Локальный плагин превращает скопированный текст тренировки FYSM Boy в Markdown-заметку и подставляет изображения из личного хранилища пользователя.

Плагин:

- не подключается к Telegram;
- не обращается к серверу FYSM;
- не содержит ссылок на методички;
- не загружает изображения в интернет;
- не изменяет исходные файлы пользователя.

## Установка тестовой версии

Это экспериментальная версия для личного тестирования. Она ещё не опубликована в каталоге Community Plugins.

### Через BRAT — iPhone, Android и компьютер

1. Установите Obsidian и создайте или откройте личное хранилище.
2. Откройте **Настройки → Сторонние плагины → Обзор**, найдите **BRAT**, установите и включите его.
3. В настройках BRAT выберите **Add Beta Plugin**.
4. Вставьте `https://github.com/sveekey/fysm-workout-importer` и подтвердите установку.
5. Откройте **Настройки → Сторонние плагины** и включите **FYSM Workout Importer**.
6. В настройках FYSM Workout Importer нажмите **Создать папки**.

### Вручную

1. Внутри хранилища создайте папку `.obsidian/plugins/fysm-workout-importer`.
2. Скопируйте в неё файлы `main.js`, `manifest.json` и `styles.css` из GitHub Release.
3. Перезапустите Obsidian, откройте **Настройки → Сторонние плагины** и включите **FYSM Workout Importer**.
4. В настройках плагина нажмите **Создать папки**.

> Перед тестированием стороннего плагина рекомендуется сделать резервную копию хранилища.

## Подготовка материалов

По умолчанию плагин создаёт и использует следующую структуру:

```text
FYSM/
└── Методички/
    ├── FYSM 1/
    ├── FYSM 2/
    ├── FYSM 3/
    ├── ZERO/
    ├── ON/
    └── SURYA/
```

Для алгоритмов папка уровня обязательна. Плагин определяет уровень по каталогу `FYSM_ALGOS` из бота и не подставит файл из другой папки. Базовое имя файла должно совпадать с точным названием алгоритма, например:

```text
FYSM/Методички/FYSM 1/Струна.png
FYSM/Методички/FYSM 2/Активация центра.png
FYSM/Методички/FYSM 3/Кайрос.jpg
FYSM/Методички/ZERO/ZERO 12.png
FYSM/Методички/ON/ON 10.png
FYSM/Методички/SURYA/Сурья Намаскар 1.png
```

Если нужного файла нет, импортёр попросит материалы по одному. На iPhone кнопка **Фото / Файлы** открывает системный выбор изображения. Плагин копирует выбранный скриншот в правильную папку, даёт ему каноническое имя и сразу переходит к следующему отсутствующему материалу. Уже добавленные схемы повторно не запрашиваются.

Поддерживаются PNG, JPG/JPEG, WebP, GIF и PDF размером до 25 МБ. В текущей версии одному элементу тренировки соответствует один файл.

## Использование

1. В Telegram скопируйте целиком сообщение со сформированной тренировкой.
2. В Obsidian нажмите иконку буфера в левой панели или откройте палитру команд.
3. Выберите **FYSM Workout Importer: Собрать тренировку из буфера обмена**.
4. Если схемы отсутствуют, добавьте предлагаемые скриншоты по одному через **Фото / Файлы**.
5. Проверьте найденные материалы и нажмите **Создать тренировку**.

Если Obsidian не разрешил автоматически прочитать буфер, вставьте текст вручную в открывшееся поле.

Готовая заметка появится в `FYSM/Тренировки`. Отсутствующие материалы будут отмечены предупреждениями; заметку всё равно можно создать.

Если комментарий явно указывает клиента — например, `Клиент: Анна`, `🔮 Оракул для: Анна` или `🍪 Пиифия для Анна: …` — плагин создаст подпапку клиента: `FYSM/Тренировки/Анна`. Обычные комментарии структуру папок не меняют.

## Разработка

Из этой директории:

```bash
npm install
npm run test
npm run build
```

Сборка создаёт `main.js`, который Obsidian загружает вместе с `manifest.json` и `styles.css`.
